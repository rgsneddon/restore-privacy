# Restore Privacy Suite v1.0.0

One app: residual Connect, Perccent wallet (**%**), and Evolve.

Installers are free on [restoreprivacy.online](https://restoreprivacy.online/).
Using residual Connect needs a KEYGEN — monthly licence from **£3.00**. Enter it
after install (app entry screen, or Settings → Payment entitlement / keygen).

The public open site lives in [`public_site/`](../public_site/) for GitHub Pages.
Operator admin is not published there.

```bash
python3 scripts/build_suite_1.0.0.py
python3 scripts/build_public_pages.py
```
