## 4. Threat model scenarios

### Scenario A — VPS compromise

Node placement: Iceland / FlokiNET. Host public materials claim no invasive connection logs. If the **guest OS** is fully compromised while sessions are live, **in-memory** material may still be exposed. Product no-log reduces durable disk history; it does not erase live RAM.

### Scenario B — ISP traffic analysis

An ISP may still see connection timing and volume. Outer obfuscation (**QUIC-mimic** when enabled) and shaping mitigate fingerprints only — not full protocol camouflage. Multi-hop residual is opt-in (`RPT_MULTIHOP_ENABLED=1`).

### Scenario C — Client device seizure

An unlocked device can expose the local device key and residual config. Packages never ship a shared client private key. **Restore Internet** erases product material on the device if run before seizure.
